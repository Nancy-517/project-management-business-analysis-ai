# 需求A_人工复核记录

## 一、复核原则

项目经理经营会前AI工作台输出的是内部参考和复核任务，不是最终经营结论。成本、验收、责任归属、亏损判断、收益承诺和对外口径必须由对应责任人确认。

## 三、角色分工

| 角色 | 必须确认的内容 |
| --- | --- |
| 项目经理 | 项目阶段、进度风险、客户反馈是否属实、下一步动作是否可执行 |
| 财务负责人 | 成本超预算或成本变化是否来自合同变更、外包、返工、差旅或付款节点 |
| 审核人 | 验收材料版本、规则冲突、对外提交口径和报告边界 |
| 授权负责人 | 收益、亏损、责任归属、客户承诺等对外表达 |

## 四、AI可做/人工必须做/禁止AI直接做

| 类型 | 内容 |
| --- | --- |
| AI可做 | 汇总项目数据、计算指标、生成风险标签、整理客户反馈、形成月报草稿和复核任务 |
| 人工必须做 | 确认异常原因、验收材料版本、客户沟通口径、最终经营判断 |
| 禁止AI直接做 | 判定项目亏损、确认验收失败、归责个人或部门、承诺收益改善、发布对外结论 |

## 六、对外表达限制

对外报告或客户沟通中，应使用“建议复核”“需要确认”“内部经营会参考”等表述，不使用“AI已判定亏损”“项目责任已明确”“验收失败”等确定性表述。

## 原型可演示内容

- 默认展示官方 P001-P008 项目数据。
- 点击"生成经营会风险分诊"后，输出高优先级、关注项目和常规跟进项目。
- 支持按风险等级筛选项目。
- 点击项目可查看成本使用率、周期使用率、质量风险、验收风险、客户反馈、证据来源和人工复核动作。
- 点击右下角"AI对话模拟"按钮，可体验模拟AI对话功能：输入自然语言问题（如"P002怎么了""哪些项目需要优先处理"），工作台基于本地数据和规则返回结构化回答，每条回复附带证据来源和人工确认提示。

## 架构设计亮点

- **状态机式工作流**：不是单次问答，而是"感知→判断→生成→复核→证据"五层状态机，支持回退和降级。详见 `workflow.json`。
- **防御性AI设计**：每层有fallback策略，AI崩溃时自动降级为原始数据透传，保证信息不丢失。
- **Skill/Memory/Guardrail解耦**：Prompt模板可复用于不同客户，项目数据动态注入，规则全局约束。
- **UX即护栏**：预设问题卡片、结构化输出、人工复核按钮等界面机制本身约束AI行为边界。
- **Local-First**：纯静态实现，数据不离开本地，满足企业数据主权要求。这不是技术妥协，而是面向产业场景的刻意选择。

## 已知限制

- 本次验证不接入真实企业系统。
- 本次验证不训练模型，不做完整项目管理平台。
- 项目风险判断只用于内部经营会前的优先级提示，不能直接判定亏损、责任归属或验收结论。
- 成本、验收、对外承诺和规则冲突相关内容必须由项目经理、财务负责人或审核人复核后再对外使用。
- AI对话模拟基于本地关键词匹配，不接入外部AI API。

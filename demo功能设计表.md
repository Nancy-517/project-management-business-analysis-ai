  demo功能设计表
  

  整体布局

  单页应用，左-中-右三栏布局 + 底部AI对话栏，无后端依赖，纯静态HTML/CSS/JS，数据内嵌P001-P008官方样例。

  ┌──────┬──────────┬─────────────────────────┐
  │ 区域 │  宽度比  │          定位           │
  ├──────┼──────────┼─────────────────────────┤
  │ 左栏 │ 25%      │ 项目导航 + 经营总览     │
  ├──────┼──────────┼─────────────────────────┤
  │ 中栏 │ 45%      │ 核心工作区（多Tab切换） │
  ├──────┼──────────┼─────────────────────────┤
  │ 右栏 │ 30%      │ 项目详情 + 人工复核面板 │
  ├──────┼──────────┼─────────────────────────┤
  │ 底栏 │ 100%固定 │ AI对话栏（可收起）      │
  └──────┴──────────┴─────────────────────────┘

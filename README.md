# 项目管理与经营分析 AI 助手

> 2026.06 京彩大创 OPC 比赛项目

基于 8 组项目经营样例数据，围绕成本、进度、质量及客户反馈设计项目经营风险分析工作台。

## 项目简介

- 构建项目总览、风险分诊、材料缺口、人工复核和经营摘要模块，辅助识别管理问题。
- 借助 AI 完成分析工作流、证据映射、可交互网页原型及参赛材料，并依据反馈持续迭代。
- 采用 Local-First 的纯静态实现，不依赖后端、数据库、私人账号、API Key 或网络服务。

## 在线与本地体验

- 在线 Demo：[打开项目经理经营会前 AI 工作台](https://ucnaluyl2vsy.aiforce.cloud/app/app_4kckzrrhv605x)
- 本地体验：下载本仓库后，用浏览器打开 [`prototype/index.html`](prototype/index.html)。

## 核心模块

- 项目总览：集中查看 P001–P008 的经营状态。
- 风险分诊：按成本、周期、质量、验收及客户反馈识别优先级。
- 材料缺口：提示当前判断缺少的项目资料。
- 人工复核：记录需要项目经理、财务或审核人确认的事项。
- 经营摘要：生成经营会前的结构化分析草稿。
- AI 对话模拟：基于本地数据和规则回答预设经营问题，并附证据来源。

## 仓库结构

```text
prototype/              可交互网页原型
outputs/                诊断报告、数据处理及复核材料
evidence/               证据地图、规则、引用与过程记录
workflow.json           分析工作流结构
answer_manifest.json    参赛提交信息
README_运行说明.md       完整运行与材料说明
```

## 使用边界

本项目使用比赛样例数据验证分析工作流，不接入真实企业系统。风险结论用于经营会前的优先级提示，不直接判定亏损、责任归属或验收结果；成本、验收和对外承诺等事项仍需人工复核。
